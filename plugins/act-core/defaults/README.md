# defaults — ワークフロー設定の既定

`/act-core:setup` が、プロジェクトのワークフロー設定（⚙️ ワークフロー設定）が空のときに `下書き` で登録するひな形。各ワークフローは、この既定の上にプロジェクトの `有効` な設定を重ねて使う（プロジェクト側が優先）。

## ファイルの形

1 ファイル = 1 件のワークフロー設定。先頭の YAML（`---` で囲む）が属性、本文の `##` 見出しが本文のセクション（記述）になる。

| 属性 | 値 |
| --- | --- |
| `name` | 名前 |
| `kind` | `辞書`／`書式テンプレート`／`抽出・判断ルール`／`参照情報` |
| `workflows` | 対象ワークフロー（`C1`、`C2`、`M6` など、または `全ワークフロー`） |
| `version` | 既定の版（登録時はプロジェクト側の版 1 として登録する） |

登録するとき、`status` は `下書き`、`maintainer` は登録した人にする。本文は見出しごとに `narrative` のセクションとして渡す。

| ファイル | 内容 |
| --- | --- |
| `term-dictionary.md` | 用語・表記辞書のひな形（C1・C2） |
| `minutes-cleanup-rules.md` | 議事録の清書ルール（C1） |
| `daily-summary-format.md` | デイリーサマリーの書式（M6） |
